# PDB Schema — Personal Destiny Blueprint

An open JSON Schema standard for agent-native self-reflection artifacts.

## Core Principle

Every assertion in a PDB must include a **falsifier**: a way to tell if it was wrong. This is the discipline that separates self-reflection from fortune telling.
